Three new words

Output file
A file the pipeline writes. Each line in it is one JSON object.
Document
The JSON object for one trade, with the rows it links to copied inside it.
Field
One place in a document, written as a path: economics.notional_usd is notional_usd inside economics.

Where a trade row ends up

Every trade row is checked. A row that passes becomes a document; a row that fails goes to the rejects file with its reasons. Documents are then added up into exposures.

Output fileOne line isBuilt from
trades.ndjsonone valid trade, as a nested documentall five tables
rejects.ndjsonone rejected trade: its id, every reason, and its cleaned valuestrades, plus the checks against the other four
exposures.ndjsonone top company: how much money is at stake with it and its subsidiariesthe documents in trades.ndjson

Our trade in the other two files

exposures.ndjson

Our trade is the latest version and not a cancellation, so it counts. It is added to the line for its top company, CP0000003 Summit Group: one more trade, gross +126,875.00 US dollars, and net +126,875.00 too, because it is a buy (a sell would subtract from net).

rejects.ndjson

Our trade passed every check, so it is not here. Step 4 shows what its line would look like if one value were bad.

What to remember

  • Three output files: trades (documents), rejects (with reasons) and exposures (totals per top company).
  • A document is one trade with every row it links to copied inside it. A field is one place in it, written as a path.
  • Each part of a document comes from one table, reached through a link.
