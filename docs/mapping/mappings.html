One new word, with seven kinds

Mapping
The rule that turns a column's raw value into a field's value. Every mapping in this project is one of seven kinds, and a column often goes through more than one, in order.

Before any mapping, every column is read as text. That is why 1,250 and N/A survive long enough for a mapping to deal with them. Correction rules you set on the Rules tab are applied during this read, so they reach every dataset.

Where each kind happens

The pipeline has five stages. The kinds run in the stages below; kind 4 runs twice, first to check that a link exists, then to copy the row in.

The seven kinds, on our trade

1Clean

Tidy a value without changing what it means: cut spaces, treat empty as missing, upper-case codes, pick one spelling.

Buy →BUY
amend→AMEND usd→USD

Used on every column.

2Parse

Turn text into a real date or number.

10/01/2025→2025-01-10
1,250→1250

Dates, quantity, price and the FX rate.

3Fill

Supply a missing value from somewhere safe, and attach a warning saying so.

N/A→2025-01-12

The trade date plus 2 days, with the warning W_SETTLEMENT_IMPUTED. An empty currency would be taken from the instrument.

Settlement date and currency only.

4Look up

Follow a link to the row it names, and copy that row in.

IN000123→instrument { … }
USD→fx_rate_to_usd: 1.0

Every link column from step 1.

5Walk

Look up again and again, following a chain to its end.

CP0004567→CP0000017→CP0000003

Top company Summit Group, depth 2, and the parents nested inside each other. The same idea gives version 2 from TR0000000017.

The two chains: company parents and trade versions.

6Calculate

Work out a new value from others.

1250 × 101.5→notional: 126875.0
× 1.0→notional_usd: 126875.0

Amounts, "is this the latest version?", and the exposure totals.

7Nest

Put each value in its place in the document, inside the right part.

quantity, price, …→economics { … }

Every document, at the end of transform.

Every column is trimmed by kind 1 first, so Clean is listed only where it is the main change. Kind 7, Nest, applies to every field, so it isn't repeated either.

What to remember

  • A mapping turns a raw value into a field's value. There are seven kinds: 1 Clean, 2 Parse, 3 Fill, 4 Look up, 5 Walk, 6 Calculate, 7 Nest.
  • Kinds 1 to 3 tidy a trade's own values. Kinds 4 to 7 bring the other tables in and build the document.
  • On our trade, every messy value from step 1 was handled by kind 1, 2 or 3.
